## 📝 Quick Customization

### 1. Update Social Links (`index.html` line 275)
```html
<a href="https://instagram.com/yourhandle" target="_blank">
    <div class="contact-icon">📷</div>
    <h3>Instagram</h3>
    <p>@yourhandle</p>
</a>
```

### 2. Add Portfolio Projects (`script.js` line 3)
```javascript
const portfolioData = [
    {
        title: 'Your Project',
        category: 'Reels',
        desc: 'Description',
        image: 'https://your-image.jpg',
        link: 'https://instagram.com/post',
        large: true
    },
];
```

### 3. Change Colors (`style.css` line 2)
```css
:root {
    --primary: #00D9FF;      /* Cyan */
    --secondary: #7C3AED;    /* Purple */
    --tertiary: #2563EB;     /* Blue */
}
```

### 4. Update Services (`index.html` line 160)
Just edit the service card emojis, titles, and descriptions.

### 5. Update Testimonials (`index.html` line 197)
Replace quotes with real client testimonials.

### 6. Update Statistics (`index.html` line 178)
Change `data-target` values for animated counters.
