## 🛠️ How to Customize

### 1. Update Social Links
**File**: `index.html`, **Line**: 275

Find and update:
```html
<a href="https://instagram.com/yourhandle" target="_blank">
```

Replace:
- Instagram URL
- LinkedIn URL
- WhatsApp number (format: +1234567890)
- Email address

### 2. Add Portfolio Projects
**File**: `script.js`, **Line**: 3

Add to the `portfolioData` array:
```javascript
{
    title: 'Your Project Name',
    category: 'Reels',  // Commercial, Music Video, Documentary, etc.
    desc: 'Short description',
    image: 'https://your-image-url.jpg',
    link: 'https://instagram.com/post-or-video-url',
    large: true  // Makes it 2 columns on desktop
}
```

### 3. Update Services
**File**: `index.html`, **Line**: 160

Edit service cards with your offerings.

### 4. Update Testimonials
**File**: `index.html`, **Line**: 197

Replace with real client feedback.

### 5. Update Statistics
**File**: `index.html`, **Line**: 178

Change `data-target` values:
```html
<div class="stat-number" data-target="150">0</div>
```

### 6. Change Colors
**File**: `style.css`, **Line**: 2

Update CSS variables:
```css
:root {
    --primary: #00D9FF;
    --secondary: #7C3AED;
    --tertiary: #2563EB;
}
```
